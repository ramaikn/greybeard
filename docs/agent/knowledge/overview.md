# Struktur skill Greybeard

- `SKILL.md` memuat instruksi lengkap; `SKILL.compressed.md` memuat versi ringkas. Perubahan aturan bersama perlu diselaraskan pada keduanya.
- `SKILL.en.md` dan `SKILL.compressed.en.md` adalah terjemahan Inggris 1:1 dari pasangan Indonesia masing-masing. Pertahankan urutan bagian/poin, aturan, angka, dan literal dalam backtick, termasuk nama tool, path, pola nama berkas, serta format status. Perubahan sumber perlu diselaraskan dengan terjemahannya.
- Bagian 8 mengatur knowledge, peta dokumentasi, log, keamanan pencatatan, dan gaya bahasa dokumen.
- Bagian 9 memusatkan aturan checklist pekerjaan: folder `docs/agent/task/`, pembuatan, status, kelanjutan, penamaan, dan pembacaan selektif.
- Pemeriksaan perubahan teks dilakukan dengan membaca bagian terkait pada kedua versi. Tidak ada pengujian kode yang diperlukan untuk perubahan dokumentasi ini.
- Repositori GitHub publik: https://github.com/ramaikn/greybeard, cabang utama `main`.
- Lingkup publikasi: versi lengkap dan ringkas skill beserta terjemahan Inggris, dokumentasi, dan `.gitignore`. Folder `old/`, `filosofi.md`, serta `idea.md` tetap lokal dan diabaikan Git.
